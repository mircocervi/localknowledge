# Regole di convivenza

Archivio nasce in aula, e in aula si impara meglio quando nessuno ha paura di fare una domanda.

- Si discutono il codice e le idee, mai la persona.
- Si parte dalla buona fede. Prima di decidere che qualcuno sbaglia, si chiede.
- Niente molestie, insulti o commenti sull'identità di qualcuno, negli issue, nelle pull request o dovunque si parli del progetto.
- Non si pubblicano dati personali di altri, neanche in un esempio.

Chi mantiene il progetto può togliere i commenti e bloccare chi non rispetta queste regole. Per segnalare un problema scrivi a mirco@mircocervi.it.
